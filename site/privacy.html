Privacy

Basic page-load counting

Before you choose an analytics preference, the site sends one BasicPageView event per page load to Microsoft Application Insights. It includes a timestamp and the site's hostname, but no cookies, visitor or session identifiers, page path, referrer, or browser/device details in the event. The event supplies a zero IP address to avoid geographic lookup. Microsoft still receives your network IP address and normal HTTP request information to deliver the request, so this is not fully anonymous at collection.

This count measures page loads, not unique visitors. Basic counting continues after acceptance, separately from visitor analytics. Rejecting stops future counting and cancels any pending basic request where possible. It cannot undo a count already received. The same rules apply when testing on localhost.

Optional visitor analytics

With your consent, Microsoft Application Insights records page views, browser and device information, cookie-based visitor and session identifiers, and approximate country, region and city. This helps Matt understand how many people visit and where visits come from. It does not identify you by name. Counts cover consenting visitors only and can be affected by blockers, VPNs and deleted cookies.

The analytics script loads only after you accept, on www.mbeard.co.uk or when testing the site on localhost. Page URLs sent to analytics exclude query strings and fragments. Referrer URLs are not sent. Automatic error and network-request collection is disabled.

Microsoft uses your IP address to estimate location. Application Insights masks stored IP addresses by default. This site does not request precise device location. Analytics is configured to send to Azure's East US 2 ingestion endpoint in the United States. Storage location and retention depend on the linked Azure workspace settings. See Microsoft's privacy statement.

Cookies and your choice

After acceptance, Application Insights uses ai_user to recognise a browser and ai_session to group visits into sessions. The SDK normally sets ai_user for one year and ai_session for up to 24 hours, with a 30-minute inactivity timeout. These are not required to use the site.

Your accept or reject choice is stored in this browser's local storage for 180 days. This preference is used only to remember your choice. You can change it using Analytics settings below. Rejecting removes this site's analytics cookies and stops future collection. It does not delete data already sent.

Other services

Azure hosts the website and processes requests to deliver it. The homepage loads fonts from Google Fonts, which receives the network information needed to serve them. Following a GitHub link takes you to GitHub, where its privacy policy applies.

Optional analytics

This site counts page loads without cookies or visitor identifiers until you choose. Accept analytics to allow Microsoft Application Insights cookies for visitor and session counts and approximate countries, regions and cities. Reject analytics to stop all counting. Your choice does not affect the site.
