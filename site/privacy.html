Privacy

Basic page-load counting

Before you choose an analytics preference, the site sends one BasicPageView event per page load to Microsoft Application Insights. It includes a timestamp and the site's hostname, but no cookies, visitor or session identifiers, page path, referrer, or browser/device details in the event. The event supplies a zero IP address to avoid geographic lookup. Microsoft still receives your network IP address and normal HTTP request information to deliver the request, so this is not fully anonymous at collection.

This count measures page loads, not unique visitors. Basic counting continues after acceptance, separately from visitor analytics. Rejecting stops future counting and cancels any pending basic request where possible. It cannot undo a count already received. The same rules apply when testing on localhost.

Optional visitor analytics

With your consent, Microsoft Application Insights and Google Analytics 4 record page views, browser and device information, and cookie-based visitor and session identifiers. Their reports can include approximate location. This helps Matt understand how many people visit and what content they read. It does not identify you by name. Counts cover consenting visitors only and can be affected by blockers, VPNs and deleted cookies.

The Application Insights script loads only after you accept, on mbeard.co.uk or when testing on localhost. Google Analytics loads only after you accept on mbeard.co.uk. Both receive page URLs without query strings or fragments, and do not receive referrer URLs. Google Analytics uses measurement ID G-0XV6WPE41G. Advertising and personalization signals are disabled.

Microsoft uses your IP address to estimate location. Application Insights masks stored IP addresses by default. This site does not request precise device location. Analytics is configured to send to Azure's East US 2 ingestion endpoint in the United States. Storage location and retention depend on the linked Azure workspace settings. See Microsoft's privacy statement.

Cookies and your choice

After acceptance, Application Insights uses ai_user to recognise a browser and ai_session to group visits into sessions. Google Analytics may set _ga and _ga_0XV6WPE41G cookies to distinguish browsers. These cookies are not required to use the site.

Your accept or reject choice is stored in this browser's local storage for 180 days. This preference is used only to remember your choice. You can change it using Analytics settings below. Rejecting disables future analytics, removes the analytics cookies this site uses and reloads the page. It does not delete data already sent.

Other services

Azure hosts the website and processes requests to deliver it. Google receives network information when this site loads Google Fonts and, after analytics consent, the Google Analytics tag. Following a GitHub link takes you to GitHub, where its privacy policy applies. See Google's privacy policy.

Optional analytics

This site counts page loads without cookies or visitor identifiers until you choose. Accept analytics to allow Microsoft Application Insights and Google Analytics to measure page views and visitors. These services may use analytics cookies. Reject analytics to stop all counting. Your choice does not affect the site.
